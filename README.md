# Python Programs

## WHAT

This repository contains three beginner-level Python programs:

* `factorial.py` : Calculates the factorial of a number entered by the user and handles negative numbers and zero.
* `fibonacci.py` : Generates and prints the first 69 Fibonacci numbers using an iterative approach.
* `student.py` : Demonstrates a basic Python class, constructor, object creation, and student attributes.

## CONCEPTS

The programs demonstrate basic Python concepts including:

* Variables and data types
* User input
* Conditional statements
* `for` loops
* Arithmetic operations
* Classes and objects
* Constructors
* Object attributes
* Formatted strings

## RUN

Execute any program through the terminal:

```bash
python factorial.py
python fibonacci.py
python student.py
```

## NEEDS

* Python 3.x
* No external libraries or packages required
